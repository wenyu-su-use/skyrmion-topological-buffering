# Field-Selected Topological Buffering in a Disordered Skyrmion Crystal

**Simulation, analysis, and visualization codes for the study of disorder-driven structural and topological changes in magnetic skyrmion crystals.**

[![arXiv](https://img.shields.io/badge/arXiv-2607.28458-b31b1b.svg)](https://arxiv.org/abs/2607.28458)

**Paper:** Wenyu Su, Nvsen Ma, Chen Cheng, and Hong-Gang Luo, *Field-Selected Topological Buffering in a Disordered Skyrmion Crystal*, [arXiv:2607.28458](https://arxiv.org/abs/2607.28458) (2026).

**Repository:** <https://github.com/wenyu-su-use/skyrmion-topological-buffering>

## 1. Overview

This repository accompanies our numerical investigation of a two-dimensional triangular-lattice chiral magnet with quenched bond-dependent Dzyaloshinskii–Moriya interactions (DMI). We examine how increasing disorder affects (i) translational order, (ii) sixfold bond-orientational order, and (iii) the net topological charge of skyrmion textures.

The central result is **field-selected topological buffering**: in one magnetic-field regime, the loss of translational coherence precedes the loss of orientational order, while the net topological charge remains approximately retained across a substantially wider disorder window. The intermediate regimes are described operationally as a **skyrmion Bragg-glass-like state (SkBG)** and a **skyrmion glass (SkG)**. At lower fields, orientational disordering and topological reconstruction move closer together, narrowing the SkG window.

The repository contains Monte Carlo simulation source code written in C++, together with Python analysis and plotting scripts. Some observables described below are evaluated in separate post-processing scripts rather than by the C++ executable alone. This README distinguishes the **paper's physical and statistical definitions** from **implementation details that must be checked against the released source**.

## 3. Model and geometry

We use classical three-component unit spins, $|\mathbf S_i|=1$, on a triangular lattice with primitive vectors

$$
\mathbf a_1=(1,0),\qquad \mathbf a_2=\left(\frac12,\frac{\sqrt3}{2}\right).
$$

For a periodic $L_x\times L_y$ lattice the number of spins is $N=L_xL_y$. The Hamiltonian written in the notation of the paper is

$$
\boxed{
\mathcal H=-J\sum_{\langle ij\rangle}\mathbf S_i\cdot\mathbf S_j
+\sum_{\langle ij\rangle}\mathbf D_{ij}\cdot(\mathbf S_i\times\mathbf S_j)
-B\sum_i S_i^z .
}
$$

Here $J>0$ is ferromagnetic nearest-neighbor exchange, $B$ is the perpendicular magnetic field, and the **bond-directed, in-plane DMI** is

$$
\mathbf D_{ij}=(D_0+\delta\eta_{ij})\,\hat{\mathbf r}_{ij},\qquad
\hat{\mathbf r}_{ij}=\frac{\mathbf r_j-\mathbf r_i}{|\mathbf r_j-\mathbf r_i|},\qquad
\eta_{ij}\overset{\mathrm{i.i.d.}}{\sim}\mathcal U[-1,1].
$$

A single random amplitude is assigned to each undirected nearest-neighbor bond and held fixed during the entire simulation of that disorder realization. Reversing the bond orientation reverses the DMI vector: $\mathbf D_{ji}=-\mathbf D_{ij}$. The disorder is **quenched DMI-amplitude disorder**, not exchange disorder. When $\delta>1$, the local DMI amplitude may change sign.

| Quantity | Paper/production convention |
|---|---|
| Lattice | 2D triangular, periodic boundaries |
| Spin length | $|\mathbf S_i|=1$ |
| DMI scale | $D_0=1$ (energy unit) |
| Ferromagnetic exchange | $J=1/3$ |
| C++ exchange convention | $J_1=-1/3$ if the code uses $+J_1\mathbf S_i\cdot\mathbf S_j$ |
| Other exchange/DMI couplings | Production choice $J_2=D_2=J_3=0$ |
| Exchange disorder | Zero in the production model |
| Final annealing temperature | $T_{\min}=0.001$ |
| Representative field cut | $B=1.2$ |
| Finite-size study | $L=60,72,90,120,150$ |

**Sign-convention warning.** The paper uses $-J\mathbf S_i\cdot\mathbf S_j$ with $J=1/3$, whereas the C++ energy representation uses $+J_1\mathbf S_i\cdot\mathbf S_j$ with $J_1=-1/3$. These describe the same ferromagnetic coupling. Likewise, do not replace the specified bond-directed DMI vector by $\hat{\mathbf z}\times\hat{\mathbf r}_{ij}$: that is a different model.

## 4. Monte Carlo sampling

### 4.1 Simulated annealing

Low-temperature configurations are generated by **geometric simulated annealing** from random high-temperature states down to $T=0.001$. An annealing step changes the temperature geometrically, $T_{n+1}=rT_n$ with $0<r<1$; the exact starting temperature, ratio, and number of sweeps are determined by the version of `input.in` and the driver source.

At fixed temperature, the simulation interleaves heat-bath spin draws with over-relaxation updates. After cooling, measurements are collected only after the final low-temperature equilibration stage. Independent quenched-disorder realizations are averaged statistically; they must not be confused with consecutive thermal samples within one realization.

### 4.2 Heat-bath update

For a spin $\mathbf S_i$ in its local effective field,

$$
\mathbf h_i^{\mathrm{eff}}=-\frac{\partial\mathcal H}{\partial\mathbf S_i},\qquad
P(\mathbf S_i\mid \{\mathbf S_j\})\propto
\exp\left(\beta\,\mathbf h_i^{\mathrm{eff}}\cdot\mathbf S_i\right),\quad \beta=1/T.
$$

The source routine historically named `MetropolisSweep` implements a **heat-bath draw** according to this local-field distribution, not necessarily a conventional Metropolis acceptance/rejection step. Consult the released routine before describing it as “Metropolis”.

### 4.3 Microcanonical over-relaxation

With $\hat{\mathbf h}_i=\mathbf h_i^{\mathrm{eff}}/|\mathbf h_i^{\mathrm{eff}}|$, the spin reflection is

$$
\mathbf S_i' = 2(\mathbf S_i\cdot\hat{\mathbf h}_i)\hat{\mathbf h}_i-\mathbf S_i.
$$

For a fixed local field this preserves $|\mathbf S_i|$ and the local interaction energy. Over-relaxation helps decorrelate spin configurations and is alternated with stochastic updates.

### 4.4 Two levels of sampling

1. **Thermal sampling:** generate and measure spin configurations for a given *fixed* disorder bond realization.
2. **Quenched-disorder sampling:** regenerate independent $\eta_{ij}$ fields, equilibrate separately, and average the resulting per-realization estimates.

For selected high-statistics analysis datasets, 56 disorder realizations with 40 stored measurement frames per realization have been used. These numbers describe specific datasets and are **not universal defaults for every parameter scan**.

## 5. Compilation and a single simulation

- A C++ compiler and `make` compatible with the repository's `Makefile` (check the flags and libraries in the actual file).

After moving the C++ files into `simulation/`:

```bash

cd skyrmion-topological-buffering/simulation
make
```

Open `simulation/input.in` and identify the settings used by your version of `main.cpp`: lattice dimensions, couplings, magnetic field, disorder amplitude or scan grid, temperatures and sweep counts, number of disorder realizations, random seed(s), output paths, and measurement intervals. Only edit options that the parser actually recognizes. Retain a copy of the input file alongside the outputs for every published run.

## 6. Parallel calculations

### 6.1 Safe, reproducible level of parallelism

The statistical problem is naturally **embarrassingly parallel across independent disorder realizations** and, when scientifically appropriate, across independent $(B,\delta,L)$ parameter points. Each job should have:

- its own independently drawn quenched bond field and **verified independent random seed**;
- its own working/output directory (avoid concurrent writes to the same filenames);
- a complete copy or record of the parameter/input file;
- an independent equilibration and measurement history.

Only after individual jobs finish should per-realization observables be combined into quenched-disorder means and uncertainty estimates. Do **not** launch multiple copies of an unchanged input file when it fixes the same random seed. This README does not claim that the currently released executable implements MPI, OpenMP, or a command-line seed flag: those must be confirmed in `main.cpp`, the `Makefile`, and the random-number initialization code.

### 6.2 Slurm job-array example (external process parallelism)

If your executable runs with no arguments and reads `input.in` from its working directory, a cluster can schedule one job per **pre-prepared** realization. For example, first prepare separate `runs/sample_000/`, `runs/sample_001/`, etc., each containing an input file with a **distinct supported seed** (or other verified mechanism producing independent disorder). Then use:

```bash
#!/bin/bash
#SBATCH --job-name=SkTB
#SBATCH --array=0-55
#SBATCH --cpus-per-task=1
#SBATCH --output=logs/%A_%a.out

set -euo pipefail
sample_id=$(printf '%03d' "${SLURM_ARRAY_TASK_ID}")
cd "runs/sample_${sample_id}"
../../simulation/exe_mc_Sky_TB
```

Create `logs/` before `sbatch` submission. This is an **illustrative cluster wrapper**, not a bundled script or a promise that all input files are generated automatically. When the C++ driver already runs many disorder realizations internally, avoid unintentionally repeating the same ensemble in multiple jobs. Set the array size according to the actual research run, not blindly to 56.

### 6.3 Combining results

For any measured observable $O$, first average over Monte Carlo measurement frames *within* each disorder sample $\alpha$ to obtain $\bar O_\alpha$. Then average these independent quenched samples as defined below. Preserve the sample-level values for uncertainty estimation, checks of convergence, and reanalysis.

## 7. Numerical observables

Notation: $N=L_xL_y$ is the spin count; $N_{\mathrm{sk}}$ is the number of identified skyrmion cores; $\mathbf R_j$ denotes core positions; $\langle\cdot\rangle_{\mathrm{dis}}$ denotes averaging over independent quenched disorder realizations. All distances and wave vectors refer to the actual **oblique triangular periodic cell**.

### 7.1 Spin structure factors

For spin component $\mu\in\{x,y,z\}$, define

$$
\widetilde S_\mu(\mathbf q)=\sum_i S_i^\mu e^{-i\mathbf q\cdot\mathbf r_i},
$$

$$
S_z(\mathbf q)=\frac{|\widetilde S_z(\mathbf q)|^2}{N},\qquad
S_\perp(\mathbf q)=\frac{|\widetilde S_x(\mathbf q)|^2+|\widetilde S_y(\mathbf q)|^2}{N}.
$$

For periodic $L_x\mathbf a_1,L_y\mathbf a_2$, reciprocal-grid vectors may be indexed as

$$
\mathbf q_{n_1n_2}=\left(\frac{2\pi n_1}{L_x},\ \frac{2}{\sqrt3}\left[\frac{2\pi n_2}{L_y}-\frac{\pi n_1}{L_x}\right]\right).
$$

The diffraction plots in the paper use the **longitudinal** $S_z(\mathbf q)$. Each displayed panel is normalized by its own maximum over $\mathbf q\neq\mathbf0$ for visualization. The FFT/structure-factor calculation uses the **entire periodic spin configuration**, not a cropped rendering window.

### 7.2 Skyrmion center extraction

Connected regions of $S_i^z<0$ are identified with periodic connectivity; components with fewer than four sites are discarded. A core position is constructed using periodic coordinates with weights $w_i=\max(-S_i^z,0)$. In the highly reconstructed magnetic-disordered-chiral regime (MDC), merging and strongly distorted cores can limit the interpretation of center-based quantities; full-spin and topological observables remain essential.

### 7.3 Translational order parameter and correlations

The skyrmion-center structure factor and reciprocal-density amplitude are

$$
S_{\rm sk}(\mathbf q)=\frac{1}{N_{\rm sk}}\left|\sum_{j=1}^{N_{\rm sk}}e^{i\mathbf q\cdot\mathbf R_j}\right|^2,
\qquad
\Psi_T^{(\nu)}=\frac1{N_{\rm sk}}\sum_j e^{i\mathbf G_\nu\cdot\mathbf R_j}.
$$

The translational amplitude is

$$
m_T=\left[\frac{1}{N_G}\sum_{\nu=1}^{N_G}|\Psi_T^{(\nu)}|^2\right]^{1/2}
=\left[\frac{1}{N_GN_{\rm sk}}\sum_{\nu=1}^{N_G}S_{\rm sk}(\mathbf G_\nu)\right]^{1/2}.
$$

The production analysis chooses Bragg reference vectors from the **clean reference texture at the same magnetic field**, compatible with the periodic box, and keeps those reference vectors fixed across disorder samples. The corresponding translational correlation is

$$
G_T(r)=\left\langle\frac1{N_G}\sum_{\nu=1}^{N_G}\cos\big[\mathbf G_\nu\cdot(\mathbf R_j-\mathbf R_k)\big]\right\rangle_{|\mathbf R_j-\mathbf R_k|=r}.
$$

Pair separations use the minimum-image convention appropriate to the oblique cell.

### 7.4 Sixfold bond-orientational order

Build a periodic Delaunay network of skyrmion centers using replicated periodic images. For center $j$ and its Delaunay neighbors $\mathcal N_j$,

$$
\psi_6(j)=\frac{1}{z_j}\sum_{k\in\mathcal N_j}e^{6i\theta_{jk}},\qquad
\Psi_6=\frac1{N_{\rm sk}}\sum_j\psi_6(j),\qquad
\Phi_6=|\Psi_6|.
$$

Here $z_j$ is the coordination number and $\theta_{jk}$ is the real-space bond angle. The bond-orientational correlation function is

$$
G_6(r)=\operatorname{Re}\left\langle\psi_6(j)\psi_6^*(k)\right\rangle_{|\mathbf R_j-\mathbf R_k|=r}.
$$

Over suitable fitting windows, algebraic and exponential envelopes are compared:

$$
G(r)\sim Ar^{-\eta}\qquad\text{and}\qquad G(r)\sim Ae^{-r/\xi}.
$$

Exclude microscopic core-scale points and unreliable long-distance bins; for oscillatory translational correlations, fit the positive peak envelope rather than an arbitrary mixture of maxima and minima.

### 7.5 Coordination defects and dislocations

A Delaunay site is a coordination defect when $z_j\ne 6$. The normalized defect fraction is

$$
\rho_{\rm def}=\frac{N_{z\ne6}}{N_{\rm sk}}=1-\frac{N_6}{N_{\rm sk}}.
$$

A dislocation core is a nearest available adjacent $5$–$7$ coordination pair, with one-to-one matching and an implemented geometric cutoff $r_{57}<1.35a_{\rm sk}$, where

$$
A=\frac{\sqrt3}{2}L_xL_y,\qquad
a_{\rm sk}=\sqrt{\frac{2A}{\sqrt3 N_{\rm sk}}}.
$$

If $N_D$ is the number of dislocation cores,

$$
n_D=\frac{N_D}{N_{\rm sk}},\qquad\rho_D=\frac{N_D}{A}.
$$

A supplementary bound/free classification identifies a dislocation as bound when a sufficiently close second dislocation (within $3a_{\rm sk}$) has an approximately opposite core-polarity direction, $\hat{\mathbf p}_a\cdot\hat{\mathbf p}_b\le-0.5$.

### 7.6 Lattice topological charge

The **net topological charge is calculated directly from all spins**, without using skyrmion-center counting. For each consistently oriented elementary triangle $(0,1,2)$,

$$
\mathcal N_\triangle=\mathbf S_0\cdot(\mathbf S_1\times\mathbf S_2),\qquad
\mathcal D_\triangle=1+\mathbf S_0\cdot\mathbf S_1+\mathbf S_1\cdot\mathbf S_2+\mathbf S_2\cdot\mathbf S_0,
$$

$$
\Omega_\triangle=2\,\operatorname{atan2}(\mathcal N_\triangle,\mathcal D_\triangle),\qquad
Q=\frac1{4\pi}\sum_\triangle\Omega_\triangle.
$$

Both orientations of elementary triangles in the lattice tiling are traversed **counterclockwise in real space**. The two-argument `atan2` is essential for the correct oriented-solid-angle branch.

For comparisons between fields and disorder strengths, define the positive charge-retention ratio

$$
\mathcal Q(B,\delta)=\frac{\langle |Q(B,\delta)|\rangle_{\rm dis}}{|Q_0(B)|},\qquad
Q_0(B)=\langle Q(B,0)\rangle_{\rm dis}.
$$

The main-text label $Q/Q_0$ denotes $\mathcal Q$ in the cited work. The topological response and characteristic disorder strength are

$$
R_Q(B,\delta)=-\frac{\partial\mathcal Q(B,\delta)}{\partial\delta},\qquad
\delta_Q(B)=\underset{\delta}{\operatorname{arg\,max}}\,R_Q(B,\delta).
$$

The derivative must be evaluated from **the normalized retention curve**, rather than normalizing its derivative afterward with an unrelated reference. Note that charge retention concerns the *net topological sector*; equal net charges do not imply identical local spin textures.

### 7.7 Disorder averages, statistical errors, and susceptibilities

For $N_{\rm dis}$ independent quenched realizations and per-realization thermal averages $\bar O_\alpha$,

$$
\langle O\rangle_{\rm dis}=\frac1{N_{\rm dis}}\sum_{\alpha=1}^{N_{\rm dis}}\bar O_\alpha,
$$

$$
\operatorname{SEM}(O)=\sqrt{\frac{\sum_\alpha(\bar O_\alpha-\langle O\rangle_{\rm dis})^2}{N_{\rm dis}(N_{\rm dis}-1)}}.
$$

The sample-to-sample structural susceptibilities are defined by

$$
\chi_O=\langle N_{\rm sk}\rangle_{\rm dis}\left(\langle O^2\rangle_{\rm dis}-\langle O\rangle_{\rm dis}^2\right),\qquad O\in\{m_T,\Phi_6\}.
$$

Uncertainties of susceptibilities can be estimated by jackknife resampling over **disorder realizations**. Independently measuring 40 thermal frames of the *same* quenched sample does not create 40 independent disorder realizations.

### 7.8 Characteristic scales and topological-buffer widths

At fixed magnetic field,

$$
\delta_T=\underset{\delta}{\operatorname{arg\,max}}\,\chi_{m_T},\qquad
\delta_6=\underset{\delta}{\operatorname{arg\,max}}\,\chi_6,\qquad
\delta_Q=\underset{\delta}{\operatorname{arg\,max}}\,R_Q.
$$

The **full topological buffer** is $\delta_T<\delta<\delta_Q$, with width

$$
W_{\rm buf}=\delta_Q-\delta_T.
$$

Its SkBG-like and SkG subwindows are, operationally,

$$
W_{\rm SkBG}=\delta_6-\delta_T,\qquad
W_{\rm SkG}=\delta_Q-\delta_6.
$$

**Important:** $\delta_6-\delta_T$ measures only the SkBG-like structural interval, not the full topological-buffer width.

### 7.9 Finite-size scaling

For order parameter $X\in\{m_T,\Phi_6\}$,

$$
X(\delta,L)=L^{-c_X}f_X\!\left[\frac{\delta-\delta_X^c}{\delta_X^c}L^{1/\nu_X}\right].
$$

The available high-field analysis uses $B=1.2$ and $L=60,72,90,120,150$. Refer to the paper and its Supplementary Material for the selected fit windows, collapse parameters, and uncertainty procedures. A finite-size collapse provides operational disorder scales over the simulated sizes and does not alone prove a new universality class.

### 7.10 Spin-texture autocorrelation (dynamical analysis)

For suitable time origins $t_0$,

$$
C_S(t)=\frac1N\sum_i\left\langle\mathbf S_i(t_0)\cdot\mathbf S_i(t_0+t)\right\rangle,
$$

$$
\mathbf M(t)=\frac1N\sum_i\mathbf S_i(t),\qquad
C_M(t)=\left\langle\mathbf M(t_0)\cdot\mathbf M(t_0+t)\right\rangle,
$$

$$
A(t)=\frac{C_S(t)-C_M(t)}{1-C_M(t)},\qquad A(0)=1.
$$

This connected normalization removes trivial persistence of the uniform magnetization. The dynamical measurement is a **separate physical diagnostic**; it should not be inferred to be an output of the static annealing executable without checking the released modules.

## 8. Reproducing the published analysis

A complete reproduction consists of distinct stages:

1. **Choose a parameter point:** $(L_x,L_y,B,\delta)$ with the desired exchange and DMI convention.
2. **Generate independent quenched samples:** draw bond amplitudes once per sample, then hold them fixed.
3. **Anneal and equilibrate:** use the verified heat-bath/over-relaxation schedule and final-temperature equilibration.
4. **Measure:** save per-realization observables and, where required, representative full-spin configurations.
5. **Aggregate:** compute quenched means, SEM/jackknife uncertainties, $\chi_{m_T}$, $\chi_6$, $\mathcal Q$, and $R_Q$.
6. **Analyze spatial organization:** locate cores, apply periodic Delaunay analysis, and compute $S_z(\mathbf q)$, $G_T$, $G_6$, and defect statistics.
7. **Determine disorder scales:** locate susceptibility and response peaks for each field, run finite-size collapses, and construct the $(B,\delta)$ map.
8. **Generate figures:** run the appropriate Python programs against their required source-data files.

To make a run independently verifiable, retain the code release/commit, precise input file, compiler/build configuration, seeds, number of disorder realizations, number of thermal measurements, output schema, and analysis-script versions. Large raw histories need not be committed to Git; data needed for the figures should be deposited separately in a persistent data repository when available.

## 9. Scientific scope and interpretation

The labels SkX, SkBG, SkG, and MDC summarize **distinct numerical regimes**, supported by combinations of structure factors, translational and orientational correlations, topological-charge retention, coordination defects, and dynamical memory. The SkBG-like label is not a claim of a rigorously established ideal 2D Bragg-glass thermodynamic phase. The lattice topological charge measures a net spin-texture topological sector, not quantum topological order.

For the actual reference results, terminology, and all parameter choices, consult the associated paper and Supplementary Material. When discrepancies arise between generic instructions in this README and the released source/configuration, the exact code plus the input accompanying a figure is the authoritative computational record.
